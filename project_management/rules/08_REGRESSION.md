# 🛡️ ЭТАЛОН ДОСТИГНУТОГО — чтобы вылеченное не возвращалось

> Вопрос, который закрывает этот файл: **делает ли система сегодня то, что мы
> доказали вчера?** До 29.07.2026 в ChessCoin на этот вопрос не отвечал никто —
> ни один автоматический контроль не проверял поведение продукта.

## Дыра, которую это закрывает

Цена по фактам проекта:

| Что | Когда работало | Когда сломалось | Сколько жило сломанным |
|---|---|---|---|
| Модал покупки попыток | чинили в апреле | вернулось к 25.04 | до жалобы Кенана |
| Cron турниров (enum `TransactionType`) | до ручных миграций | ~09–10.05 | **до 14.05**, ошибка глушилась в логах |
| Иконка splash без синего фона | утверждено 19.04 | откатилось при фиксе `useAuth` | замечено Кенаном «за миллисекунду» |
| Бот: ретрай заблокированного пользователя | — | 10.07 17:34 | **19 дней**, найдено 29.07 при инициации |

Ни один случай не был чьей-то небрежностью — не было механизма, который
проверяет **поведение**, а не инфраструктуру.

## Как устроено

Таблица `chesscoin_pm.regression_cases`: тема → команда проверки → что **обязано**
быть в выводе / чего быть **не должно** → когда доказано → из какой аварии родилось.
Проверка идёт боевым путём. Результат каждого прогона — в `regression_runs`.

```bash
python project_management/tools/regression.py
```

- Прогон **после каждого фикса** и перед словом «готово».
- Упавший случай перепроверяется второй раз — разовый сбой сети не поднимает тревогу.
- Тревога Кенану — **только если случай раньше проходил, а теперь упал**.

## Долг и регрессия — разные вещи

- 🚨 **регрессия** — случай раньше проходил, теперь упал. Сообщать немедленно.
- ⏳ **долг** — случай ни разу не проходил. Это работа впереди, не поломка.

## Что охраняется сейчас (8 случаев, заведено 29.07.2026)

| Тема | Род | Родилось из |
|---|---|---|
| Сайт отвечает 200 | infra | базовая доступность |
| Backend health: `status:ok`, `db:ok` | api | падение БД замечали по жалобе игрока |
| Все 8 контейнеров `Up` | infra | после reboot часть не поднималась |
| В логах backend нет `prisma:error` | db | AUDIT 14.05: cron падал каждый час |
| Enum `TransactionType` = 36 значений | db | рассинхрон схемы ломал турниры, донаты, войны, TON |
| Прод не отстаёт от `origin/main` | infra | коммиты не доезжали до прода |
| Cron топ-батлов отработал за час | api | молчащий cron выглядит как «не работает функция» |
| Бот не зациклен на `Failed to send notification` | bot | ⏳ **долг**: идёт с 10.07, не исправлено |

## Правило пополнения — со счётчиком

Любой **вылеченный** дефект добавляется в эталон в тот же день. Строка ✅ в
`registry/TODO_FIXES.md` без записи в `regression_cases` считается незакрытой.
`session_start.py` печатает `помечено закрытыми: N | случаев в эталоне: M`
и ругается, если закрытых больше.

## Визуальный эталон — закрытие главной слепой зоны (добавлено 29.07.2026)

Инфраструктуру и логику контур ловил, а то, из-за чего Кенан ругался чаще всего —
съехавшую панель, вернувшуюся старую иконку, чужой шрифт — не видел вовсе.

```bash
python project_management/tools/visual.py compare     # снять и сравнить
python project_management/tools/visual.py approve 04_shop   # утвердить новый вид
python project_management/tools/visual.py list        # что в эталоне
```

- Эталон: `design_canon/baseline_screens/` — **17 экранов**, версионируются в git
  наравне с шаблонами.
- Съёмка: `scripts/playwright-screenshots.mjs`, viewport iPhone 14 Pro (390×844),
  токен тестового пользователя через штатный эндпоинт `/screenshotter/token`.
- Сравнение попиксельное; порог `2%` (ниже — шум анимаций и таймеров).
  Карты различий сохраняются, видно **где именно** разошлось.
- `approve` — только по явному слову Кенана. Утвердить текущий вид = объявить
  его каноном; сделать это молча означает узаконить регрессию.

**Чему научила первая же съёмка.** Скрипт отрапортовал «✅ 18 скриншотов», а на
семи из них был ErrorBoundary «Something went wrong»: настоящий
`telegram-web-app.js` перетирал мок, и `CloudStorage.getItems` из `PageLayout`
падал с `WebAppMethodUnsupported`. Счётчик файлов доказывал только то, что файлы
созданы. Поэтому в инструменте есть проверка содержимого, а не только наличия —
и поэтому же дефект `PageLayout` попал в `TODO_FIXES` (№14): на клиенте без
CloudStorage то же самое увидит живой игрок.

## Честная граница

Эталон **не** даёт стопроцентной страховки. Он охраняет только то, что в него
внесено, и ловит пропажу за сутки вместо недель. Он не поймает: поведение, которое
мы никогда не проверяли; ухудшение дизайна, не сводимое к команде; смысловой сдвиг
в игровом балансе. Список охраняемого нужно пополнять — в этом и состоит работа.

**Слабое место именно ChessCoin:** большая часть его дефектов — визуальные
(шаблон, отступы, иконка, положение кнопки), а они плохо сводятся к автоматической
проверке. Поэтому визуальную часть охраняет не эталон, а `09_TEMPLATES.md` —
закон шаблонов и сверка с git.
