# 🟥 ЗАКОН ШАБЛОНОВ — специфика ChessCoin

> Это правило нужно именно этому проекту: большинство упрёков Кенана — не про
> падения сервера, а про **дизайн, который переделали без спроса**.
> Автоматическая проверка тут почти бессильна, поэтому защита — процедурная.

## Закон

**Утверждённые Кенаном шаблоны неприкосновенны.** Любое расхождение текущего
кода с шаблоном чинится **возвратом к шаблону**, а не написанием новой версии.

Заменить иконку, шрифт, цвет, размер, отступ или расположение в утверждённом
шаблоне можно **только по явной просьбе Кенана в текущей сессии**.
Никаких «я думала будет лучше».

## Алгоритм правки UI-компонента

1. Есть ли TPL-шаблон? — grep по имени в `TEMPLATES_INDEX.md`.
2. Есть — сравнить текущий код с шаблоном. Расхождения **откатить к шаблону**, не «улучшать».
3. Нет шаблона — `git log --all --follow -- <path>`: когда файл менялся, какая
   версия долго стояла в проде и не вызывала жалоб. Она и есть эталон.
4. Нет ни того ни другого — писать свой код и **сразу сохранить как новый шаблон**
   (или согласовать с Кенаном).

## Запрещено

- создавать новый SVG-компонент с нуля, когда аналог есть в шаблоне
  *(16.05: `IcoDice` → самописный `IcoShuffle`, откатила)*;
- менять размеры/отступы/цвета, если они приходят из шаблона;
- «упрощать» шаблон;
- эмодзи в UI Mini App — только SVG-иконки в стиле проекта
  (тонкий stroke, `currentColor`, viewBox 20×20 или 32×32);
- `window.innerWidth` — только CSS media queries;
- любая иконка монеты, кроме `frontend/src/components/ui/CoinIcon.tsx`
  (золотой конь, viewBox 32×32).

## Канон, зафиксированный Кенаном (не переспрашивать, не «улучшать»)

- **HomePage и JARVIS Play Modal** — эталоны стилистики. Любая новая страница
  или модал повторяет их.
- **Критические модалы** (подтверждение, выход из режима, покупка) — **по центру**,
  не bottom-sheet. `useConfirm` для подтверждений, `Modal` для bottom-sheet.
- **Заголовки страниц** — единый шрифт/размер/позиция, эталон — страница «Войны».
- **Сообщения «нельзя играть / нужно купить»** — toast на 3 секунды, не мигающая полоса.
- **ELO** — под аватаром, центрирован, на тон светлее.
- Полный список одобренного — `MASTER_PLAN.md` § 1 (белый список, менять только
  по явному «переделай X»).
