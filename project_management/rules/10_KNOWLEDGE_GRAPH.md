# 10. Граф знаний проекта

Карта всего проекта одним связным полотном: код, схема базы, управляющие
документы и **история решений** — почему сделано именно так.

Поставлен по просьбе Кенана 05.08.2026: «карта всего проекта как на ладони —
доступна, видна комплексно и связанно».

## Где смотреть

| Файл | Что это |
|---|---|
| `graphify-out/graph.html` | интерактивная карта, открывается в браузере без сервера |
| `graphify-out/GRAPH_REPORT.md` | разбор: узлы-концентраторы, неожиданные связи, вопросы |
| `graphify-out/wiki/index.md` | вики по сообществам — точка входа для агента |
| `graphify-out/graph.json` | сам граф, для запросов и внешних инструментов |

Папка `graphify-out/` **в git не хранится** — 6 МБ генерируемых файлов.
Пересобирается одной командой на любой машине.

## Как обновить

```bash
# 1. Выгрузить свежую историю решений из памяти проекта
python project_management/tools/export_history.py

# 2. Пересобрать граф (разберёт только изменившееся)
graphify . --update
```

Полная пересборка — `graphify .` без флага. Разбор кода бесплатный и быстрый;
смысловой разбор документов идёт через подагентов и стоит токенов, поэтому
`--update` предпочтительнее.

## Почему история решений — отдельный файл

Граф читает файлы, а разговоры с Кенаном живут в памяти проекта
(`claudia_memory.dialog_history`). Без выгрузки карта показывает **устройство**
кода, но не **замысел**: видно, что `payFromTreasury` вызывается из десяти
мест, но не видно, что так сделано после того, как монеты дважды печатались
из воздуха.

`export_history.py` кладёт решения в `docs/history/DECISIONS.md` рядом с кодом,
и граф связывает правило с дефектом, который его породил.

## Что граф уже показал

- **Узлы-концентраторы:** `useT()` (100 связей), `logError()`, `fmtBalance()`,
  `updateBalance()`. Правка любого из них задевает весь проект.
- **Причинная цепочка управляющего контура:** ошибка → корень → правило →
  механизм. Каждое железное правило связано с дефектом, который его вызвал.
- **Противоречия в каноне** — три несовместимые версии распределения призов
  войны в разных документах; побеждает новейший по дате.
- **Мусор, который врёт:** `frontend/ts_errors.txt` — лог от 18.04, все ошибки
  давно исправлены, но граф честно вытащил из него три несуществующих дефекта.

## Чему не верить без проверки

Проверено 05.08.2026 после пересборки: **висячих связей ноль**, ссылок на
удалённые файлы ноль. Прежняя запись про «508 висячих» была ошибкой —
столько связей отбросил сам сборщик во время разбора, в готовый граф они
не попали. Считать надо по `graph.json`, а не по строчке из вывода сборки:

```bash
python -c "import json,io; g=json.load(io.open('graphify-out/graph.json',encoding='utf-8')); ids={n['id'] for n in g['nodes']}; print(sum(1 for e in g['links'] if e['source'] not in ids or e['target'] not in ids))"
```

Что действительно требует осторожности — **уверенность связи**, её помечает
сам граф:

| Метка | Сколько | Что значит |
|---|---|---|
| `EXTRACTED` | 5186 | сказано прямо в источнике — можно опираться |
| `INFERRED` | 225 | вывод разбора — проверить по коду |
| `AMBIGUOUS` | 3 | догадка — решений не строить |

В `graph.html` неуверенные связи нарисованы пунктиром и бледнее сплошных,
так что глазу они не мешают. Пять `AMBIGUOUS` на пять тысяч — это доли
процента; отвлекать они не могут, но и ссылаться на них нельзя.

**После правки кода** граф обновляется без затрат на модель:
`graphify update .` — разбирает только изменившееся, ключ не нужен.
Смысловой разбор документов (`graphify . --update`) стоит токенов и нужен
только когда менялись сами документы.

## Что обновляется само, а что руками

`python project_management/tools/sync_graph.py` вызывается на каждом входе в
сессию (из `session_start.py`) и делает две бесплатные вещи: выгружает свежие
решения из ЦНС и пересобирает граф ПО КОДУ. Ключ для этого не нужен.

**Смысловой разбор документов — руками**, командой `/graphify --update`. Он
читает изменившиеся документы подагентами и стоит токенов, поэтому в
автоматический ход не поставлен. Запускать, когда менялись каноны, правила
или выгрузка решений — иначе граф будет знать устройство кода, но не замысел.

Выгрузка решений **накапливается**: раньше файл переписывался последними
80 записями и каждый запуск выбрасывал прежние. Теперь новое дописывается
к старому (Кенан 09.08.2026: «иначе будет тянуть назад»).
