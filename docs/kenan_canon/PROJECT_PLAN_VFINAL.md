# ChessCoin — финальный план развития

> **Источники:** `GAME_REQUIREMENTS_FROM_KENAN.md` (канон) + `GAME_DESIGN_KNOWLEDGE.md`
> (текущее состояние v7.1.0). План построен только из требований Кенана. Где
> требования отсутствуют — задача не включена.

## Принципы плана

1. **Ничего не выдумано.** Каждая задача — отсылка к разделу спеки и/или цитате
   `[YYYY-MM-DD HH:MM]` Кенана.
2. **P0 = блокер пользовательского пути** (нельзя играть/открыть/выйти).
   **P1 = доходообразующее** (комиссии, биржа, донаты).
   **P2 = UX-консистентность.**
   **P3 = полировка.**
3. **Последнее по timestamp побеждает**, поэтому промежуточные «как делали раньше»
   не превращаются в задачу.
4. Оценки часов — экспертные, основаны на сложности и области (фронт/бэк/дизайн).
